# 서울 기후 변화 분석 대시보드

119년(1907~2026)간 축적된 서울 지역 일일 기온 데이터를 활용하여 지구 온난화의 경향성을 시각적으로 분석하는 웹 애플리케이션입니다.

## 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 데이터 출처 | 기상청 기상자료개방포털 (지점번호 108, 서울) |
| 관측 기간 | 1907-10-01 ~ 2026-06-18 |
| 데이터 수 | 42,931건 (일 단위) |
| 분석 도구 | Python, Pandas, Plotly, Streamlit |

## 데이터 구조

| 컬럼명 | 자료형 | 설명 |
|--------|--------|------|
| 날짜 | 문자열 | 관측 일자 (앞부분에 탭 문자 포함, 전처리 필요) |
| 지점 | 정수 | 관측 지점 번호 (108 = 서울) |
| 평균기온(℃) | 실수 | 일 평균 기온 |
| 최저기온(℃) | 실수 | 일 최저 기온 |
| 최고기온(℃) | 실수 | 일 최고 기온 |

## 주요 분석 결과

- 연평균 기온: 1907년 약 5.10℃ → 2026년 약 10.06℃ (약 4.95℃ 상승)
- 선형회귀 기울기: 연간 약 +0.0416℃
- 관측 최고 기온: 39.6℃ (2018-08-01)
- 관측 최저 기온: -23.1℃ (1927-12-31)
- 평균 일교차: 약 9.28℃

## 구현 기능

1. **추세선 분석** - 연도별 평균기온, 5년 이동평균, 선형회귀선을 함께 표시
2. **월별 히트맵** - 월과 연도를 축으로 하는 격자 형태의 기온 분포
3. **계절 분석** - 계절별 기온 분포를 바이올린 플롯과 연대별 꺾은선으로 비교
4. **기록 조회** - 최고 기온 및 최저 기온 상위 10개 사례와 극값의 연도별 변화
5. **일교차 분석** - 연도별 일교차 추세와 월별 평균 일교차

사이드바에서 차트 유형, 연도 범위, 계절을 선택하여 결과를 즉시 변경할 수 있습니다.

## 데이터 전처리 유의사항

원본 CSV의 날짜 컬럼 값 앞에는 탭 문자가 포함되어 있으므로, 날짜형으로 변환하기 전에 반드시 공백을 제거해야 합니다.

```python
df['날짜'] = df['날짜'].str.strip()
df['날짜'] = pd.to_datetime(df['날짜'])
```

이 과정을 생략하면 날짜 변환 단계에서 오류가 발생합니다.
